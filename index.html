ℹ️ About Gaslands Game Manager

This web app was built for the love of the game is provided free of charge. It is a completely unofficial, non endorsed, fan made, unauthorised bootleg addtion to the game. There's no support. You're smart, I'm sure you'll figure things out. That being said there will be updates as I use it and fix things that annoy me. I'll keep a eye on reddit too. If you use it a lot you might fancy buying me a beer or coffee to say thanks, no pressure I would have made this anyway! But as a way of saying thank you back all supporters get a supporter badge/flair next to the user name. Thanks to Mike for being ace.

🏷️ Version History & Updates

v1.0.5 - Current Release 02.11.26
  • Smartphone Portrait Tabletop Overhaul: Ultra-refined layouts specifically tailored for narrow mobile screens (360px–430px). Eliminated all horizontal viewport stretching and clipping.
  • Zero-Truncation Turn & Gear Phase Tracker: Engineered a compact 2-row tracker for mobile screens: Game Turn (- 1 +) and all 6 Gear Phase buttons ([1][2][3][4][5][6]) fit side-by-side on Row 1; Dice controls (Type, Count, Key, History, Roll) fit cleanly on Row 2 with flexible, non-overflowing controls.
  • Collapsible Audience Votes HUB: Integrated quick +1 Vote and collapsible 🎟️ Perks ▾ accordion on smartphones, preserving 250px+ vertical dashboard visibility while keeping canonical perks one tap away.
  • Play Mode Header Compression: Automatically hides Garage setup inputs (Team Name, Sponsor, Budget, Total Spent) on mobile/tablet when in Play Mode, bringing active vehicle dashboards to immediate thumb view.
  • Fluid Swipeable Mode Navigation: Full-width horizontal swipe navigation bar with momentum scrolling on mobile devices.
  • Garage Actions 2x2 Grid: Reorganized top garage buttons (Add Vehicle, Clear Team, Export Team, Import Team) into a clean, finger-friendly 2x2 grid.
  • Multi-Homed LAN Server Architecture: Validated node static server daemon bound to 0.0.0.0:8080 with verified Windows Firewall private network permissions for seamless cross-device phone/tablet tabletop play over local Wi-Fi.
  • AI Prompt Generator Overhaul: Foremost untextured clay render prompts with 3D miniature printing optimization (watertight manifold geometry, 28mm–32mm scale), Bambu AMS multi-material 4-colour FDM palette selector, and cinematic action-movie crew postures (1 driver actively steering even if armed, remaining crew actively leaning out and firing config-chosen weapons).
v1.0.4 01.11.26
  • Adaptive Tablet & Phone Auto-Detection: Integrated intelligent DeviceManager that auto-detects hardware device class (phone, tablet, desktop) and orientation (portrait, landscape), dynamically tailoring dashboard layouts, grids, touch targets, and typography.
  • Mobile-Optimized Touch Controls: Thumb-sized touch targets for Hull checkboxes, Hazard tokens, and Gear selector buttons (min 36-40px) to prevent accidental miss-taps during tabletop play.
  • Responsive Multi-Column Grids: Tablet portrait now displays balanced 2-column vehicle grids instead of stretched single cards; phones use clean single-column cards with touch-friendly spacing and hidden watermarks for optimal readability.
  • Compact Landscape Viewports: Specialized low-profile headers and turn/phase trackers for smartphones in landscape orientation, maximizing vehicle dashboard viewability.
  • Tactical Radio Comms & Active Roster: Real-time in-game radio communications with split chat scrollback and active driver roster, draggable & resizable window on desktop, and a sleek bottom-sheet drawer with collapsible roster on mobile.
  • Audio FX Synthesizer: Web Audio API tactical sound chimes for incoming messages and alerts, with global "Mute All Sounds" toggle in Settings and Comms window.
  • Persistent Driver ID & Supporter Badges: Auto-generated persistent Driver IDs, Ko-fi donation link, and VIP badge activation system.
  • Default Online Lobby Routing: All players automatically route to the central Online Lobby upon connecting before choosing WAN, LAN, or Auto tables.
v1.0.3 01.11.26
  • Online Table Lobby & Matchmaker: Added a real-time lobby where drivers can idle and chat before entering a game table. Includes instant live player counts, table directory, and quick matchmaker.
  • Host Management & Kick: Table creators are assigned Table Host status (👑 HOST badge) and can kick unwanted players from the table.
  • Auto LAN Table Custom Naming: Customizable friendly name for the local Same-WiFi Auto LAN table (e.g. "Basement Brawl", "Living Room LAN").
  • Default Garage Screen: Automatically defaults to Garage Mode on load and switches back to Garage Mode when joining any table.
  • Version & Updates Location: Relocated version indicator to the bottom of the About modal with click-to-view applied updates history.
v1.0.2 - Night Vision & Custom Logos 01.11.26
  • Settings Menu: Replaced the top navigation bar 'About' button with a unified 'Settings' modal.
  • Hide AI Prompt Button: Added a toggle switch in Settings to hide or show the AI Image Prompt buttons.
  • Custom Sponsor Logos: Upload custom team sponsor images (PNG, JPG, WEBP, SVG) with live preview, automatic local persistence, and instant reset.
  • Light & Dark (Night Vision) Modes:
    • Light Mode: Original classic Camouflage & Desert Sand theme.
    • Dark Mode: Red and black theme designed specifically to preserve night vision in darkened rooms during tabletop play.
    • Follow System: Automatically follows your device's light/dark mode setting.
  • Version & Updates Access: Updated bottom-left indicator to v1.0.2 with double-click access to the full update changelog.
v1.0.1 - Rules, Multiplayer & Assets 31.10.26
  • Vehicle Special Rules: Displayed directly on Play Mode cards.
  • Team & Sponsor Traits: Integrated on Play Mode vehicle cards.
  • Per-Vehicle Multiplayer Sync: Damage and hazards are now tracked and synced individually per vehicle rather than as a team total.
  • Audience Vote Perks: Added missing "Carpe Diem" perk.
  • Dice Roller Stability: Fixed white-screen crash when rolling dice while on fire; capped max dice count to 10.
  • Sponsor Rules Fix: Resolved persistent sponsor rules remaining when no sponsor is selected.
  • Sponsor Logos: Switched to official sprite sheet (sponsor_logos.jpg) and corrected Miyazaki and Mishkin sprite cropping.
  • AI Tools: Streamlined tools exclusively to the 3D Image Prompt Generator.
